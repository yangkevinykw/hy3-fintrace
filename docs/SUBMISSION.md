# FinTrace 项目提交说明

## 项目目标

面向财务表格与报告问答，分别判断最终答案和显式计算过程，并定位第一个已确认错误。核心演示是：把 8 + 14 写成 23，却在最后给出正确答案 22；只检查最终答案会漏掉过程错误。

## 已交付内容

- 可本地运行的中文工作台：证据高亮、步骤核验、错误传播、JSON 编辑重评、结果导出。
- Hy3 真实解答与语义评审适配器，保留失败状态、原始响应和续跑能力。
- 确定性规则、Hy3 Judge、混合评估三种方式；公式不同但无法证明错误时允许弃权。
- 固定版本 FinQA 的 30 道题与 90 个受控过程，公开来源、筛选方式和指标分母。
- 30 道题的真实解答及评审、三组对照的已运行结果、重复评审的尝试记录。
- 两个独立子智能体完成的 AI 复核与评测报告，以及针对发现问题的回归测试。
- 真人复核页面、项目说明、实验协议、演示操作步骤和 GitHub 自动测试配置。

## 评审者快速体验

先观看 [1 分 56 秒演示视频](../demo/fintrace-demo.mp4)，包含实际网页操作、中文旁白与章节说明。

需要 Python 3.11 或以上版本，无第三方运行依赖。克隆仓库后双击根目录的 `启动工作台.cmd`，或者运行：

```sh
python scripts/serve_batch_workbench.py
```

打开 http://127.0.0.1:8765/ 。默认案例展示“答案正确但过程错误”。在“批量评测”中查看统计、参考争议，并载入已经保存的真实解答；这些功能无需 API 密钥，也不会消耗接口额度。

只有点击“使用 Hy3 解答”或重新开展在线实验时，才需要按 `.env.example` 配置本地 `.env`。

## 主要结果与解释

|内容|结果|
|---|---|
|离线测试|36 项通过|
|官方程序执行交叉核验|30/30 一致|
|真实解答与语义评审|30/30 成功|
|答案符合原始 FinQA 程序|20/30|
|AI 对真实答案的复核|28 份有题面支持、2 份范围未定|
|AI 对参考过程提出争议|8 道题，包含年份错配和增长方向颠倒|
|独立 AI 评测核对|19 项通过，发现的 3 个实现问题已修复|

原始参考符合率与 AI 复核意见是不同指标，AI 意见不能当成人工金标。完整数字和分歧见 [批量实验报告](../runs/experiments/batch-v1/REPORT.md)。

## 提交版本边界

本次提交包含可运行系统、真实实验产物与复核材料。接口在批次后半程返回 HTTP 402：受控评审成功 69/90，额外重复评审成功 1/24，仍有 44 项待恢复服务后续跑；目前不能得出重复稳定性结论。失败没有被删除或替换。

已提供独立 AI 复核材料。数值舍入契约和重复数字证据粒度仍有已记录的边界。项目没有对外部署服务，原始密钥、原始接口响应和全量缓存不提交到 GitHub。

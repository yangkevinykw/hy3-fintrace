# FinTrace 项目说明

FinTrace 面向财务表格和报告问答，结合确定性核验与 Hy3 语义评审，检查最终答案、定位第一处错误，并追踪错误对后续步骤的影响。

## 演示入口

[观看演示视频](../demo/fintrace-demo.mp4) · [查看实验报告](../runs/experiments/batch-v1/REPORT.md)

需要 Python 3.11 或以上版本。在仓库根目录运行：

```sh
python -X utf8 scripts/serve_batch_workbench.py
```

浏览器访问：[http://127.0.0.1:8765/](http://127.0.0.1:8765/)

Windows 也可双击 `启动工作台.cmd`。默认案例展示 `8 + 14 = 23`、最终答案为 `22` 的过程错误；点击步骤可查看证据，修改中间结果后可立即重新评估。

## 核心功能

| 模块 | 内容 |
| --- | --- |
| 证据追踪 | 定位财报表格、文字和取数位置 |
| 过程核验 | 检查输入、依赖、局部算术、公式等价和答案衔接 |
| 错误定位 | 标记首个已确认错误及受影响步骤 |
| 语义评审 | 使用 Hy3 判断公式、范围与财务含义 |
| 批量评测 | 比较规则、Judge、Hybrid 三组，按固定分母统计 |
| 交互工作台 | 案例切换、编辑重评、复核记录、报告导出和真实解答回放 |

## 数据与验证

- 固定 FinQA 30 道题，开发集 10 题、评测集 20 题，按财报隔离。
- 30 个参考过程、60 个受控错误过程，覆盖取数、计算、依赖和公式变更。
- 30 道题的真实 Hy3 解答及语义评审。
- 官方执行器交叉核验 30 / 30 一致；36 项项目测试通过。
- 原始构造标签下，规则组检出 45 / 60，混合组检出 57 / 60，两个组的参考过程误报均为 0 / 30。

真实答案对原始 FinQA 程序的符合率为 20 / 30。样本口径、参考争议及完整调用记录见实验报告，评价方法见[方法与指标](METHOD.md)。

## 技术实现

后端使用 Python 标准库，前端使用原生 HTML / CSS / JavaScript。规则执行器仅运行受支持的四则指令；结构化解答通过本地接口核验。Hy3 配置从本地 `.env` 读取，新增在线调用时使用；保存的案例、结果和报告可直接离线浏览。

# FinTrace 功能清单

| 模块 | 实现内容 |
| --- | --- |
| 数据准备 | 固定版本下载、30 题筛选、来源清单、报告隔离与 90 个受控过程构造 |
| 计算执行 | 四则运算、数值与百分比处理、参考程序回放、官方执行器交叉核验 |
| 规则评估 | 输入结构、证据值、依赖、局部计算、符号等价、答案衔接、说明与运算一致性 |
| 错误分析 | 首个已确认错误、后续传播、三态判定、答案正确但过程错误识别 |
| Hy3 接口 | 真实解答、语义评审、响应保存、错误记录、有限重试与配置指纹 |
| 批量评测 | 规则 / Judge / Hybrid 对照，按划分、难度和错误类型统计 |
| 工作台 | 证据高亮、案例切换、JSON 编辑重评、结果导出与解答回放 |
| 案例复核 | 匿名编号、初次判断前隐藏结论、不可覆盖的初始记录 |
| 实验产物 | 固定题集、逐题结果、参考争议、敏感性分析和批量报告 |
| 项目验证 | 48 项测试、30 题官方交叉核验、Windows / Ubuntu 自动测试 |
| 演示材料 | 工作台视频、中文旁白、字幕、章节说明与录制脚本 |

运行入口见[项目 README](../README.md)，结果统计口径见[实验报告](../runs/experiments/batch-v1/REPORT.md)。

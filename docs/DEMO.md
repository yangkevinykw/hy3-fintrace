# 演示流程

1. 启动本地页面，说明本次演示使用保存的 FinQA 受控过程，不是实时模型响应。
2. 打开一个“标准过程”，查看原始表格/文字、计算步骤和结构化判定范围。
3. 打开 IQV/2018/page_106.pdf-1 的挑战案例：8 + 14 被写成 23，但最终答案仍写 22。展示答案正确与过程错误的独立判断，以及 s1 的证据。
4. 点击步骤，定位引用的原始数值；展示程序计算值和模型声称值。
5. 打开公式挑战，说明为什么局部算术通过也不能直接判定推理成立；此时规则会返回无法确定。
6. 打开批量评测，展示开发/评测分组、每项指标分母、公式类检出局限和人工复核状态。
7. 打开人工复核，展示提交前隐藏结论的流程；不要为了演示伪造真实人工标签。
8. 在批量评测中点击“查看解答与证据”，载入已保存的真实 Hy3 解答，无需在线调用。区分原参考符合率与 AI 复核意见，展示参考争议。需要新增在线解答时才配置接口。

录制视频时避免拍到 .env 或密钥。项目目前提供操作脚本，尚未生成最终视频。

# FinTrace 演示说明

[观看视频](../demo/fintrace-demo.mp4) · [字幕与旁白稿](../demo/README.md)

演示使用实际工作台中的受控案例与保存的 Hy3 解答，包含中文旁白和八个章节。

## 操作顺序

1. 启动工作台，查看问题、原始证据、计算轨迹和审计结论。
2. 展示 `8 + 14 = 23` 的挑战案例，观察“答案正确、过程错误”的独立判定。
3. 点击计算步骤，定位报告文字中的数值来源。
4. 将中间结果修改为 `22`，重新评估并查看更新后的结论。
5. 打开批量评测，对比规则、Hy3 Judge 和混合评估的结果。
6. 展开参考争议，查看年份、增长方向和范围问题的逐题依据。
7. 载入保存的 RCL 财务问答，回看真实解答的证据、计算与评审结果。
8. 展示项目仓库与文档入口。

新增在线解答时，在 `.env` 中配置 Hy3 接口，然后点击“使用 Hy3 解答”。
